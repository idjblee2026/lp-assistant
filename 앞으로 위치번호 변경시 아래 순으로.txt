앞으로 선반 정리를 하시거나 위치 번호만 변경하실 때는 아래 순서대로만 진행하시면 됩니다:

1단계: lp_list.xlsx 엑셀 파일을 열어 위치 번호를 원하는 대로 수정하고 저장(Ctrl + S)합니다.

2단계: 폴더에서 까만 창(cmd)을 엽니다. (Alt + D 누르고 cmd 입력 후 엔터)

3단계: 명령어 python remap_locations.py를 입력하고 엔터를 칩니다.

이렇게만 해주시면 외부 AI를 부르지 않으므로 토큰 비용은 100% 무료(0원)이며, 웹 화면의 검색 데이터베이스(lp_database.json)에 바뀐 번호가 즉시 깔끔하게 반영됩니다.
